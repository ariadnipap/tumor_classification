# Tumor Classification via MRI Radiomics

This project focuses on the use of **Magnetic Resonance Imaging (MRI)** for brain tumor staging (Brain Tumor Classification) through the extraction and analysis of **radiomic features**. It was developed as part of the Biomedical Engineering lab coursework at the National Technical University of Athens (NTUA).

---

## Project Description
The goal of the project was to build a machine learning pipeline to classify brain tumor stages based on radiomic features extracted from MRI images. The methodology combined **feature engineering, feature selection**, and **machine learning models** to improve classification accuracy and provide more targeted insights for treatment planning.  

---

## Key Highlights
- Extracted **radiomic features** from MRI scans.  
- Applied **feature selection** methods to enhance classification performance.  
- Trained and evaluated multiple **machine learning algorithms** for tumor staging.  
- Analyzed the role of radiomics in improving diagnostic accuracy.  

---

## Technologies Used
- **Python**  
- **Scikit-learn** (classification, feature selection, evaluation)  
- **Radiomics libraries** (feature extraction from MRI images)  
- **NumPy**, **Pandas**, **Matplotlib**
